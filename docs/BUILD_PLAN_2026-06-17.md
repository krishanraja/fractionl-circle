## 8. Risks + what stays gated

- **Cohort honesty gate (hard, Fork 3), and the headline first-impression gap.** Day-one `n=0` for every cohort, so the marquee "N comparables who started where you are" differentiator is INVISIBLE at launch (everything renders "benchmark says"). This is honest and acceptable, but it is the biggest first-impression gap and is designed-for, not discovered: the corpus seed must carry placement + fork-naming + gap on benchmark framing ALONE. The per-cohort `n` framing unlocks only as consented paths accrue (P2). The 3x-fixed-scope number ships `expert_opinion`, never `hard_telemetry`. One visible fabrication poisons every reading, so this gate ships before any Decision Room copy.
- **Inference-quality gate (P0.5).** The New-vs-Seasoned classifier (fully net-new, NOT mostly-`extract-identity`) and the lit-fork scorer can misread. Mitigation: confidence floor (blank-but-honest beats confident-but-fabricated), the one-tap correction writing `the_read.manual_override` permanently (protects a $45K/mo operator from New-grade scaffolding), and `gap-engine`/`rank-inner-circle` blanking any row they cannot ground.
- **Provider gate (P0.5 blocker, not a nicety).** `extract-read` MUST ship with Gemini/Anthropic fallback because OpenAI billing is exhausted and `extract-identity` is OpenAI-only with a hard 503 dead-end. P0 sidesteps this entirely by writing `the_read` directly from pills (no LLM), which is exactly why P0 ships before the inference layer.
- **Statelessness gate (law WHO, query-layer enforced).** `rank-inner-circle` re-derives from `circle_person`+`signals` each call and reads NO prior `matches`/decision-touch rows for ranking; the re-purposed `matches` table is never read as contact history. A code-review check on the function guards this: any read of a prior per-person status is a CRM regression.
- **Ledger-not-eventlog gate (law FORK soft drift).** `decision_ledger` stores decisions + reasoning + outcome only; `LedgerMock` must render as a quiet decision history, never a browsable activity/event timeline.
- **Monetization-gate-keys-before-free-surfaces (review point, the "free users self-grant Pro" RLS class).** The cohort-depth gate keys (`cohort_patterns`/`divergent_branches`/`parallel_path`/`forward_landmines`) are DEFINED and server-checkable in P0 even though enforcement lands in P1, so we never ship free access we later claw back.
- **Deletion-safety gate (verified).** No `moves`/`move_edits`/`talent_*` table is dropped without amending the `compliance_hardening` per-user delete-sweep array (`20260602000002:34-38`) in the SAME migration, or per-user deletion breaks.
- **Latency/cost gate.** Path open reads cached `the_read` + deterministic placement; only `extract-read` and `decision-engine` are LLM-backed and both fire on explicit action. No Path open blocks on serial LLM calls.
- **What we fake first.** Cohort `n` (faked as "benchmark says" until P2); the comparable tracks behind the Path (population benchmarks + peer-path archetypes until consented paths accrue); the parallel-Path modeling (P2); the LLM Read (stubbed as direct pill-write in P0, real in P0.5); person enrichment beyond OAuth metadata (P2). The Path placement, the Gap deltas, and one resolved decision are REAL in P0 on the corpus seed.
