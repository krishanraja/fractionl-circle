# Archived strategy docs

These describe earlier directions, superseded by the current product. They are kept for
history only. The product that shipped is the thesis-validation engine: see
[`docs/PRODUCT.md`](../PRODUCT.md).

- **PRODUCT_DIAGNOSIS_2026-06-16 / UX_REBUILD_VISION_2026-06-03** - the original Circle
  relationship-to-revenue CRM and its rebuild audit.
- **DREAM_STATE_VISION / DESIGN_LANGUAGE / BUILD_PLAN (2026-06-17)** - the Path Room, an
  adaptive decisioning surface that was the intermediate direction before the pivot to the
  thesis-validation engine.
- **roadmap.md** - the old Circle roadmap.

**Root-level files also superseded (not yet moved here):**
- `DOCS.md` at the repo root — was the comprehensive Circle CRM spec ($0/$30/$79 tiers,
  Ideas/Matches/Moves/Streams ontology, Sunday Letter, Match Engine). A deprecation notice
  has been added at the top; recommend moving it here as `DOCS_CIRCLE_CRM_2026-05-30.md`.
- `docs/google-oauth-setup.md` / `docs/microsoft-oauth-setup.md` — describe Google/Microsoft
  Contacts+Calendar OAuth sync, a feature that existed in Circle CRM and is not in the
  thesis product UI. Notices added; recommend moving here if the feature is not re-activated.
